# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Email
**hello@clusterbite.com** with a description, the affected version and, if possible, steps
to reproduce. We aim to acknowledge reports within three working days and will keep you
informed while we work on a fix.

Relevant areas include: crashes or excessive resource use on crafted Python files or
notebooks, and `--fix` writing outside the files it was given.

## Supported versions

sparklint is in early development (0.x). Fixes go into the latest release only.
